WEEK 13.2 WEBSITE STARTER

Files to upload together to the root of a public GitHub repository:
- index.html
- about.html
- projects.html
- style.css

Steps:
1. Sign into GitHub. Get your exact username.
2. Create a PUBLIC repository named YOUR-USERNAME.github.io. Check Add a README if offered.
3. Upload all four site files (not this README.txt unless you want it). Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Open https://YOUR-USERNAME.github.io, and click all three menu links.
6. Fill in the real link and results in week13-2_Zhanadi.docx, then submit Word and URL to Moodle.
